**BandwagonHost는 어떤 업체인가**

성격을 한 줄로 요약하면 "대형 클라우드 업체가 아니라, 회선에 돈을 쓰는 전통적 VPS 업체"다. 하드웨어는 자체 운영 장비를 사용하고, 모든 플랜에 RAID-10 스토리지와 1~10Gbps 업링크가 붙는다. 공식 기준 가동률 보장은 99.9%이고, 노드는 매분 모니터링된다고 밝히고 있다.
